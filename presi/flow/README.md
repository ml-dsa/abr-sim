# presi flow scripts

This directory contains the small Python tools used by the Adams Bridge
presilicon simulator prototype.

- `vf_to_sv2v.py` parses the Verilator-style file list generated by the
  top-level Makefile and runs `sv2v`.
- `gen_yosys.py` emits Yosys scripts for coarse, SRAM-blackboxed, and
  experimental gate-mapped netlists.
- `spice_to_c.py` translates the experimental SPICE gate netlist into
  xpresi-style ANSI C include files.

The flow is intentionally close to `../xpresi`: generated artifacts live in
`presi/_build`, while checked-in scripts stay small and inspectable.

Current gate-mode status: `make netlist-gates` keeps the ten main AB SRAMs
blackboxed, but still times out at the default 180 second budget because other
lookup memories and tables are expanded into registers before mapping.  This is
useful evidence that the next practical boundary is broader than just
`abr_1r1w_ram` and `abr_1r1w_be_ram`.
